# Требования к Social Media Preview Image (og-image.png)

## Технические требования

- **Размер:** 1200x630 пикселей (оптимальный для Facebook, LinkedIn, VK)
- **Формат:** PNG или JPG
- **Имя файла:** `og-default.png`
- **Расположение:** `public/og-default.png`
- **Размер файла:** до 1 МБ

## Содержание изображения

### Обязательные элементы:
1. **Логотип ProfReport** - в верхнем левом углу
2. **Основной заголовок:** "Профориентация с ИИ"
3. **Подзаголовок:** "Найдите свою профессию за 15 минут"
4. **Визуальный элемент:** иллюстрация или фото, связанное с профориентацией
5. **Домен:** profreport.online (небольшим шрифтом внизу)

### Цветовая схема:
- Фон: градиент от `#3B82F6` (primary) до `#8B5CF6` (secondary)
- Текст: белый (#FFFFFF) для контрастности
- Акценты: использовать цвета из дизайн-системы сайта

### Безопасная зона:
- Оставьте отступы минимум 40px со всех сторон
- Центральная часть 1200x630px - самое важное содержимое
- Избегайте мелкого текста (минимум 40px для основного текста)

## Инструменты для создания

### Рекомендуемые онлайн-сервисы:
1. **Canva** (https://www.canva.com/) - шаблоны Open Graph
2. **Figma** (https://www.figma.com/) - профессиональный дизайн
3. **OG Image Generator** (https://og-image.vercel.app/) - быстрое создание

### Готовые шаблоны:
- Canva: поиск "Open Graph Image Template" или "Social Media Cover"
- Размеры уже настроены на 1200x630px

## Тестирование

После создания проверьте изображение:
1. **Facebook Debugger:** https://developers.facebook.com/tools/debug/
2. **Twitter Card Validator:** https://cards-dev.twitter.com/validator
3. **LinkedIn Post Inspector:** https://www.linkedin.com/post-inspector/

## Альтернативные изображения (опционально)

Можно создать специальные og-image для разных страниц:
- `/og-tests.png` - для страницы тестов
- `/og-about.png` - для страницы "О нас"
- `/og-faq.png` - для страницы FAQ

Указывайте их через параметр `ogImage` в BaseLayout:
```astro
<BaseLayout
  title="..."
  description="..."
  ogImage="/og-tests.png"
/>
```
